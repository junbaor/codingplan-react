## ⚠️ 注意事项

1. **额度计算方式**
   - 编程工具中一次用户提问通常触发多次模型调用（5-30次）
   - 各平台计量方式不同，详见官网说明

2. **首月特惠**
   - 火山引擎和阿里云提供首月优惠
   - 注意续费价格

3. **使用限制**
   - 大部分采用滚动5小时窗口限额
   - 阿里云仅主账号可用，不支持 RAM 用户

4. **退款政策**
   - 大部分平台不支持订阅后退款
   - 建议从低档套餐开始体验

## 📚 常见问题

**Q: 什么是 Coding Plan？**
A: 国内 AI 平台推出的编程专属订阅套餐，按月/季/年订阅即可在 AI 编程工具中畅用大模型，无需按 token 付费。

**Q: 5小时限额是什么意思？**
A: 滚动5小时窗口限制。例如 40 prompts/5小时，意味着任意5小时内最多发送40次提问，额度随时间自动恢复。

**Q: 哪个平台性价比最高？**
A: 取决于需求。入门推荐 MiniMax Starter 或火山引擎/阿里云首月特惠；看重模型多样性选火山引擎；看重 MCP 工具选智谱。

**Q: 可以退款吗？**
A: 大部分平台不支持订阅后退款，建议先从低档套餐试用。
