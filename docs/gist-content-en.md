## ⚠️ Things to Know

1. **One prompt ≠ one API call** — A single prompt in a coding tool typically triggers 5–30 model calls behind the scenes
2. **Rolling 5-hour window** — Most platforms refresh quota on a rolling basis, not at fixed times
3. **Annual plans save money** — MiniMax offers 2 months free on annual billing
4. **No refunds** — Most platforms don't offer refunds after subscription; start with a lower tier
